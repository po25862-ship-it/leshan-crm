# 私人開發信

入口：`#/outreach`、首頁捷徑、物件資料中的「建立私人開發信」。副系統使用相同實作與同一個 Firebase 帳號範圍。

- `outreachPrivate/{uid}` 下保存收件紀錄、檔案版本、寄送批次與寄件設定。所有讀寫限 UID 本人，既有管理者 catch-all 明確排除此路徑。此為應用程式權限隔離；雲端專案維運權限仍由專案擁有者管理。
- Storage 路徑為 `outreachPrivate/{uid}/{sha256}`。本人驗證後使用 `getBlob` 下載；不產生或保存公開下載連結。檔案內容去重，每份限 5MB，介面檔案庫上限 50MB；不自動變更帳務方案。合併列印檔僅在瀏覽器產生，離開後釋放。
- 上傳原稿照原內容列印；文字範本支援 `{{姓名}}`、`{{案名}}`、`{{地址}}`、`{{物件地址}}`。更改文字範本建立新版本。
- 原檔 PDF 保留頁面；圖片適配 A4。信件與標籤使用相同收件順序，分為兩個 PDF 以便換紙。標籤為 105×74mm、A4 2欄4列，上下各0.5mm。列印選100%實際大小。
- 產生、確認列印、實際寄出分開登記。歷程記下當時信件版本、收件地址與姓名；同一案件同日的寄出事件使用固定 ID，交易內檢查避免重複計次。歷程不可覆寫。
- 停用、不再寄送、退件案件須先處理後才能列印。待補案件僅在使用者明確選擇後略過。篩選不會偷偷取消或擴大寄送名單。
- 郵遞區號由需登入的 `/api/outreach-postal` 轉送至中華郵政公開地址轉換服務。僅傳收件地址，回傳中文地址與六碼；無唯一結果時不猜填。手動六碼必須勾選核對，地址改動後重新核對。查詢不保存伺服器端地址日誌，回應不得快取。
- 同事可各自匯入／匯出名單、保存批次、整批登記寄出、記錄退件、設定追蹤。首頁顯示本人今日／逾期提醒；不發送外部訊息。資料用頁面讀取與手動更新，沒有新增持續監聽或定時掃描。
- 校正值僅存在目前裝置、按帳號區分。未使用檔案可由本人刪除；已有歷程版本保留原檔，只提供停用。

驗證：`src/lib/outreachModel.test.js`、`src/pages/OutreachLetters.test.js`、`scripts/outreach-postal.test.cjs`、`scripts/test-outreach-rules.cjs`。權限測試呼叫官方 Rules Test API，不讀寫真實收件資料。

## 私人案件來源整合

- 「案件資料」匯入一份 HTML 及地址 PNG/JPG/WebP 或 ZIP。parse5 以惰性樹解析，不執行腳本、不追連結、不載入遠端圖片，因此不重新向地政付費查詢。只提供 HTML 而缺圖時清楚提示；可補圖或手動輸入。
- 保留原始電傳文字、計算用平方公尺與持分及地址圖片，合為惰性 JSON，沿用私人檔案庫 50MB 上限，單份5MB。移除原 HTML 的腳本、登入憑證連結及外部資源屬性；不將 HTML 放進 iframe。SHA-256 依實際保存內容去重，不受下載檔名影響。
- 依縣市、行政區、段與建號確定同一案件，門牌／樓層／面積由使用者再核對；相同遮蔽姓名不合併所有權人。公設與車位按各共有部分持分換算，最後才四捨五入，缺少資料保留待確認。
- 地址圖可在目前裝置用 Tesseract.js 辨識；只下載公用辨識程式／語料，圖片不傳到辨識服務。辨識結果須由使用者對照原圖確認。
- 公開售屋網址目前直接支援信義：需登入的 `/api/outreach-listing` 僅允許固定信義主機及案件路徑，禁重新導向、不記錄正文，限流及逾時。只取對應 houseNo 的 contentData，避開推薦物件及成交價；讀不到時保留手動輸入，不猜填。
- `outreachPrivate/{uid}/cases` 保存私人案件、共有人、價格歷程及來源ID；`sourceFiles` 保存來源中繼資料；Storage `outreachPrivate/{uid}/sources/{sha256}` 僅本人可驗證下載，沒有管理者跨帳號例外或公開網址。
- 只將勾選且已核對的收件人加入原有 records；每位獨立建立紀錄或明確選擇原紀錄。交易內核對案件／收件紀錄版本，保留原 letterId、狀態、備註、寄出次數和子集合歷程。新增收件ID依案件與登記次序固定，重試不建立第二份。
- 可只儲存案件而不建立收件紀錄；真正寄出仍需在既有寄送名單中另行登記。新增功能沒有定時掃描、外部訊息或持續監聽。

## 貼上電傳文字

在「開發信 → 整合物件資料」選「貼上電傳文字」，貼上有層次與縮排的 YAML／JSON，按「讀取電傳文字」，即可進入原本的案件核對頁並填入售屋網址，不必先上傳 HTML。

- 每次一間物件、最多 20 萬字；建物標示部須有完整建號（縣市、行政區、地段、建號）與門牌。
- 支援主建物、附屬建物、共有持分及其含停車位持分，沿用 HTML 匯入的面積計算。缺少或矛盾的持分不猜數字。
- 所有權部須保留每位所有權人的登記次序，影像辨識地址可直接帶入；遮蔽姓名不當成完整收件姓名。
- 他項權利人的地址不當成所有權人地址，抵押權設定金額不當成售價或尚欠貸款。
- 只有路名、缺少門牌號碼的地址可先隨案件保存，補齊且核對後才能加入寄送名單。
- 文字在目前裝置整理，儲存後才將原始文字及計算依據存到本人私人工作區；不使用付費文字辨識服務。
