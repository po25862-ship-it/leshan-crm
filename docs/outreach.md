# 私人開發信

入口：`#/outreach`、首頁捷徑、物件資料中的「建立私人開發信」。副系統使用相同實作與同一個 Firebase 帳號範圍。

- `outreachPrivate/{uid}` 下保存收件紀錄、檔案版本、寄送批次與寄件設定。所有讀寫限 UID 本人，既有管理者 catch-all 明確排除此路徑。此為應用程式權限隔離；雲端專案維運權限仍由專案擁有者管理。
- Storage 路徑為 `outreachPrivate/{uid}/{sha256}`。本人驗證後使用 `getBlob` 下載；不產生或保存公開下載連結。檔案內容去重，每份限 5MB，介面檔案庫上限 50MB；不自動變更帳務方案。合併列印檔僅在瀏覽器產生，離開後釋放。
- 上傳原稿照原內容列印；文字範本支援 `{{姓名}}`、`{{案名}}`、`{{地址}}`、`{{物件地址}}`。更改文字範本建立新版本。
- 原檔 PDF 保留頁面；圖片適配 A4。信件與標籤使用相同收件順序，分為兩個 PDF 以便換紙。標籤為 105×74mm、A4 2欄4列，上下各0.5mm。列印選100%實際大小。
- 產生、確認列印、實際寄出分開登記。歷程記下當時信件版本、收件地址與姓名；同一案件同日的寄出事件使用固定 ID，交易內檢查避免重複計次。歷程不可覆寫。
- 停用、不再寄送、退件案件須先處理後才能列印。待補案件僅在使用者明確選擇後略過。篩選不會偷偷取消或擴大寄送名單。
- 郵遞區號由需登入的 `/api/outreach-postal` 轉送至中華郵政公開地址轉換服務。僅傳收件地址，回傳中文地址與六碼；無唯一結果時不猜填。手動六碼必須勾選核對，地址改動後重新核對。查詢不保存伺服器端地址日誌，回應不得快取。
- 同事可各自匯入／匯出名單、保存批次、整批登記寄出、記錄退件、設定追蹤。首頁顯示本人今日／逾期提醒；不發送外部訊息。資料用頁面讀取與手動更新，沒有新增持續監聽或定時掃描。
- 校正值僅存在目前裝置、按帳號區分。未使用檔案可由本人刪除；已有歷程版本保留原檔，只提供停用。
