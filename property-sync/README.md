# 樂善 CRM 物件每日同步

這是僅在使用者 Mac 上執行的桌面同步工具，不會把登入密碼或內部編號放進 GitHub。

## 同步流程

1. 從 4 間店、16 種物件類別下載完整 64 份報表；少一份就中止，不寫入 CRM。
2. 依委託書編號去重並下載詳細資料，補上座落、主建物、附屬建物、公設與車位資訊。
3. 讀取已登入後台查詢表的「官網點閱」欄位；有數字超連結才標記官網已上架，沒有超連結就標記未上架。頁面涵蓋率不足 90% 時視為登入失效，整批官網狀態不更新。
4. 登入 Firebase，先將現有物件存成同步前 JSON 備份。
5. 以委託書編號精準更新；保留人工備註，價格異動另寫歷程。
6. 第一次未出現在完整報表只記錄，連續第二次未出現才自動標記「暫時不賣」。人工暫停與已售物件不會被自動改回。
7. 產生 18 個工作表的 `物件總表_匯出_YYYY-MM-DD.xlsx`、原始 64 份報表、詳細頁與同步紀錄。

## 本機入口

執行 `npm run server` 後開啟 <http://127.0.0.1:8877/>。首次設定會把 CRM 密碼與內部編號存入 macOS 鑰匙圈，並安裝每天 07:30 的 LaunchAgent。CRM 的桌面版「立即同步」按鈕也會開啟這個頁面；手機版不顯示。

## 安全測試

`npm run test:archive` 只讀取測試封存，不會連線或寫入 Firebase。正式寫入必須明確加上 `--apply-crm`，且 64 份來源全部驗證成功。

## 社區與商圈回填

`node backfill-property-locations.js` 只會預覽可由案名、地址與 A7／A8／A9 路段可靠判斷的結果。確認後使用 `node backfill-property-locations.js --apply` 才會先備份現有資料並補入空白欄位；人工已填內容不會被覆蓋。每日同步也會保留並沿用同一套判斷規則。
